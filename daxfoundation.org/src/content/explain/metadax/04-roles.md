    more: "Per learner, per concept, per moment: a set of roles (subject teacher, tutor a step ahead, psychologist, parent, community) instantiated as agents, aimed at one person, swapped as the context changes. Fractions gets one thirty; a first week at a bakery gets another. Integrated over a lifetime it is thousands of agents, each with a bounded moment on this one learner. The channel is symmetric: the guide gets a fan-out too. The state that makes it coherent is the learner's record (reached, tried, not yet), not any one agent's chat. A chat is hands and ears. The record is the body."
    how: "Shipped today: a package. The guide's loop is the one thing not automated: observe this learner at this juncture, decide. An agent is only as good as the human it answers to. Next: always-on agents per concept per moment, the companion as the primary interface, and public experiments that establish the schemas: the record, reuse by meaning, guides in the loop."

This page is an instance of the same discipline: an edition is schema data, never markup, and every edition is signed. The one you are reading, included."
